# TailGram 2.0 🐶

Мессенджер без сервера: переписка, звонки, истории и группы напрямую между устройствами (P2P / WebRTC).

## Скачать

| Платформа | Файл | Размер | Требования |
|:--|:--|--:|:--|
| 🪟 Windows | `TailGram-Windows-x64.zip` | 465 КБ | Windows 10/11 x64 |
| 🤖 Android | `TailGram.apk` | 149 КБ | Android 7.0+ |

**Установка на Windows:** распакуйте ZIP в любую папку и запустите `TailGram.exe`.
WebView2 Runtime, если его нет в системе, установится автоматически при первом запуске.
Не вытаскивайте `exe` из архива — рядом должны быть три WebView2-библиотеки, они уже в архиве.

**Установка на Android:** скачайте APK на телефон, разрешите установку из этого источника
и откройте файл. При первом запуске приложение попросит микрофон и камеру.

## Что нового в 2.0

- ✏️ Редактирование своих сообщений с пометкой «изменено» (синхронизируется у собеседника и в группах)
- 📬 Офлайн-доставка: отправленные офлайн сообщения уходят, когда собеседник снова в сети
- 🟢 Индикатор «печатает…» в шапке чата и в списке чатов
- 🔄 Автоматическая проверка соединений каждые 25 секунд вместо ручного обновления
- 🇬🇧 Первая версия для Android (APK)
- 🪟 Windows-сборка: весь интерфейс вшит в один `.exe`, HTML/JS-файлы больше не нужны

Полный список изменений — в [CHANGELOG.md](https://github.com/dimacultasov6-star/TailGram/blob/main/CHANGELOG.md).

## Возможности

Переписка · голосовые · кружки · фото и файлы · звонки · реакции · группы и каналы ·
истории на 24 часа · подарки и звёзды · закреп · озвучка текста · крестики-нолики

## Приватность

Сообщения идут напрямую между устройствами, сервер хранения не используется.
История, контакты и настройки хранятся только локально на вашем устройстве.
